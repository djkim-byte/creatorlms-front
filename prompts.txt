================================================================
DRONE 메뉴 페이지 작업 - 사용자 프롬프트 모음
================================================================

[1] DRONE 메뉴 콘텐츠 생성 요청 (이미지 첨부: 다크 톤 DRONE INTELLIGENCE 화면)
----------------------------------------------------------------
DRONE 메뉴 콘텐츠를 만들고 싶어
- 공통 GNB와 공통 푸터를 적용해서 만들어 주세요.
- 첨부한 화면으로 콘텐츠를 만들어 주세요.
   * 리스트가 모두 펼쳐지게 해주세요.
   * 최대 3줄로 요약해 주시고 리스트를 클릭하면 상세화면으로 이동하게 만들어 주세요.


[2] 배경 색상 변경
----------------------------------------------------------------
바탕색은 하얀색 바탕으로 만들어 주세요.


[3] 번역 버튼 영역 제거 (이미지 첨부: 번역 (EN↔KO) 버튼)
----------------------------------------------------------------
리스트 화면마다 있는 첨부한 영역을 모두 없애줘. 상세페이지까지 포함해서 삭제해 주세요.


[4] 리스트에 첨부파일 표시 추가
----------------------------------------------------------------
리스트 요약 콘텐츠 아래 첨부파일이 있을 경우 표시해 주고 첨부파일을 클릭하면 다운로드 할 수 있도록 해주세요.


[5] 상세 페이지에 첨부파일 표시 추가
----------------------------------------------------------------
상세페이지를 수정합니다.
- 제목 위에 첨부파일이 있을 경우 첨부파일을 다운로드 받을 수 있도록 해주세요.


[6] 상세 페이지 미디어 삽입
----------------------------------------------------------------
상세페이지 제목 밑에 사진이나 동영상이 있을 경우 크게 삽입해 주세요.


[7] 첨부파일 표시를 파일포맷만 노출
----------------------------------------------------------------
첨부파일 표시가 파일명은 보여지지 않고 파일포맷만 표시해줘


[8] 첨부파일 디자인 변경 (이미지 첨부: PDF 아이콘 + 다운로드 화살표)
----------------------------------------------------------------
첨부파일 표시 내용을 수정해줘
- 첨부한 파일 형식으로 만들어 주시되 세로로 긴형말고 가로로 긴형으로 만들어 줘
- 엑셀은 xls, PPT는 PPT로 표시해줘


[9] 다운로드 시 저장 위치 선택
----------------------------------------------------------------
다운로드 버튼을 클릭시는 저장할 공간을 찾을 탐색창을 호출해줘


[10] 프롬프트 추출
----------------------------------------------------------------
이때까지 사용했던 프롬프터를 모두 텍스트 파일로 뽑아줘
